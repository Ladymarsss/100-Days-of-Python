# Python Turtle Mini Projects 🐢

This repository contains small practice projects I built while learning the **Python Turtle module**.

They are beginner exercises, but each one helped me understand graphics, loops, randomness, angles, and drawing logic more deeply.

---

## 📂 Projects Included

---

### 🎲 Random Walk

A simple program where the turtle moves in random directions and creates a colorful path.

**Concepts practiced:**
- Random module
- Loops
- Direction control
- RGB colors
