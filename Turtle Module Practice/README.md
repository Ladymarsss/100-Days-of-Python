# Python Turtle Mini Projects 🐢

This repository contains small and simple practice projects I built while learning the **Python Turtle module**.

They are beginner exercises, but each one helped me understand graphics, loops, randomness, and drawing logic a little better.

---

## 📂 Projects Included

### 🎲 Random Walk
A simple program where the turtle moves in random directions and creates a colorful path.

Concepts practiced:
- Random module
- Loops
- Direction control
- colors

---

### 🔷 7 Shapes
A program that draws multiple geometric shapes (from triangle to higher-sided polygons).

Concepts practiced:
- For loops
- Angles in geometry
- Repetition patterns

---

### ➖ Dashed Line
A basic dashed line drawing using alternating forward and pen-up movements.

Concepts practiced:
- Looping patterns
- Pen control (penup / pendown)
- Step-based logic

---

## 🎯 Purpose

These projects were created to:

- Practice the Turtle module
- Strengthen my understanding of loops and logic
- Learn by experimenting
- Get comfortable building small programs independently

Even though they are small, they represent important steps in my learning process.

- Random module (for the random walk)
