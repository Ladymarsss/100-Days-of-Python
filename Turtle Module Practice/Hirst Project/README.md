# Hirst Dot Painting – Python Turtle 🎨🐢

A 10x10 grid of colorful dots generated using Python’s Turtle module.  
Each dot’s color is randomly selected from a predefined palette.

---

## 📖 Project Description

This project recreates a grid-style dot painting inspired by Hirst-style artwork using Python’s Turtle graphics module.

The program positions the turtle at a starting coordinate and uses nested loops to draw evenly spaced dots in a structured 10x10 layout. Each dot is assigned a random color from a predefined list.

---

## 🛠 What This Project Does

- Moves the turtle to a fixed starting position
- Draws 10 rows
- Each row contains 10 evenly spaced dots
- Selects a random color for each dot
- Creates a clean and structured grid pattern
