# 🎯 Number Guessing Game (Python)

## 📌 Description
This is a **console-based Number Guessing Game** built in Python as a **flying solo project** for **Day 12 of the *100 Days of Python* course**.

The project was created by observing a demo of the game and recreating the logic independently, without following a step-by-step tutorial. The game challenges the player to guess a randomly generated number between **1 and 100**, with different difficulty levels.

---

## 🕹️ How the Game Works
- The game randomly selects a number between **1 and 100**
- The player chooses a difficulty:
  - **Easy** → 10 attempts
  - **Hard** → 5 attempts
- After each guess, the game provides feedback:
  - `"Too High"`
  - `"Too Low"`
- The game ends when:
  - The correct number is guessed ✅
  - The player runs out of attempts ❌
- The player can restart the game after winning or losing

---

## 🛠️ Technologies Used
- **Python 3**
- `random` module
- Functions & loops
- Conditional logic
- User input handling
